# דף נחיתה – שיעורי AI פרטיים לבעלי עסקים

Next.js (ייצוא סטטי) + Tailwind. מוכן לפריסה ב-Vercel.

## הרצה
```bash
npm install
npm run dev     # פיתוח: http://localhost:3000
npm run build   # בונה לתיקיית out/
```

## בדיקות
```bash
npm test         # בדיקות יחידה (vitest): התוכן, הטופס, הטלפון, קישורי הוואטסאפ
npm run verify   # בדיקה בדפדפן אמיתי על האתר הבנוי (צריך npm run build קודם)
npm run check    # הכול: lint, בדיקות יחידה, build ו-verify
```
- **אימות עם Zod** (המקבילה ל-pydantic): `src/lib/schema.ts`. כל התוכן ב-`site.ts` נבדק בכל בנייה, ותוכן שבור (למשל מספר וואטסאפ לא תקין) עוצר את הבנייה עם הודעה בעברית. הטופס בודק שם, טלפון ישראלי (ומנרמל אותו) וסוג עסק, ומציג שגיאה ליד כל שדה.
- **תמונות:** `tests/images-baseline.json` שומר טביעת אצבע של כל קובץ ב-`public/img` ואת מיקום כל תמונה בדף. `npm run verify` נכשל אם משהו מהם השתנה. כשמחליפים תמונות בכוונה, מעדכנים את הקובץ הזה.

## איפה עורכים
- **כל הטקסטים, פרטי הקשר והמחירים:** `src/content/site.ts`
- **צבעים, גדלי טקסט וצורת "הבועה":** `src/app/globals.css` (בלוק `:root` בראש הקובץ)
- **תמונות:** `public/img/` – תמונת ההירו (`lesson.webp`) והחיתוכים ממנה
- **הטופס:** `src/components/LeadForm.tsx` – כרגע פותח וואטסאפ עם הפרטים
- **המלצות:** מוסתרות. להפעיל עם `testimonials.show = true` ב-`site.ts` רק כשיש המלצות אמיתיות

כל ערך שמתחיל ב-`[למלא` מוצג בדף כתגית צהובה עד שממלאים אותו.

## מה עוד צריך למלא
- [ ] כתובת האתר הסופית (`siteUrl`, נדרש לתמונת השיתוף)
- [ ] תמונה אמיתית של זיו (`public/img/` + `about.photoSrc`)
- [ ] אישור לדוגמאות בחלק "מה בונים בשיעור" (`build.examples` – תוכן לדוגמה)
- [ ] המלצות אמיתיות (כשיהיו)
- [ ] לאן הלידים מהטופס צריכים להגיע (מייל / Google Sheets / CRM)
- [ ] מזהי Google Analytics / Meta Pixel (`analytics` ב-`site.ts`)
- [ ] נוסח הצהרת נגישות + פרטי רכז נגישות (לבדוק מול גורם מוסמך)
- [ ] נוסח מדיניות פרטיות (לבדוק מול גורם מוסמך)

## עיצוב
העיצוב נבנה עם הסקיל `design-taste-frontend` (בתיקייה `.agents/skills/`).
הרעיון: צורת "בועת הודעה" (שלוש פינות מעוגלות ואחת ישרה) חוזרת בכל הדף – מסגרת תמונת ההירו, הכפתורים, הנקודות ברשימות והכרטיסים.
אין מחירים בדף, בכוונה.
